# Sample media

Optional demonstration assets can be placed here. They are not required for normal operation.

The current dependency-free file source accepts a single image or a directory of image frames (sorted lexicographically), for example:

```
samples/office-frames/001.png
samples/office-frames/002.png
```

Container decoding (MP4/AVI/etc.) remains behind the VideoSource boundary and will be added with a dedicated decoder backend.
